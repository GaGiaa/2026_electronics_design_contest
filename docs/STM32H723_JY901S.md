# STM32H723 JY901S 接入说明

## 硬件与 CubeMX

JY901S 使用 `UART9`，由 STM32CubeMX 图形界面配置并生成：`PG0=UART9_RX`、`PG1=UART9_TX`、8-N-1、`234000 bit/s`、DMA1 Stream2 RX、DMA 与 UART9 中断。模块 TX 接板端 `PG0`，模块与板端必须共地；`PG1` 仅保留给后续模块配置命令。

模块当前回传设置为 200 Hz。接线前必须确认供电和 UART IO 电平与 H723 板端 3.3 V 兼容。

## 数据与调试

应用以 FreeRTOS 5 ms 节拍读取 UART9 ReceiveToIdle DMA 软件环形缓冲，解析标准 11 字节帧：

- `0x55 0x51`：三轴加速度和温度，分别按 `raw / 32768 * 16 g`、`raw / 100 degC` 换算。
- `0x55 0x52`：三轴角速度，按 `raw / 32768 * 2000 deg/s` 换算。
- `0x55 0x53`：Roll、Pitch、Yaw，按 `raw / 32768 * 180 deg` 换算。

所有帧验证前十字节累加和。`volatile g_h723_debug` 的 `jy901s` 分组可通过 Keil SWD Watch 观察十项原始/物理量、车体坐标量、陀螺零偏、校准状态、样本有效性与年龄、DMA 活动状态、帧计数和接收错误计数。

服务在每个完整样本发布后，还通过 `h723_jy901s_service_get_snapshot()` 提供序列号保护的控制快照。快照包含 `vehicle_angle_deg[1]`、完整样本序号、样本时间、样本有效性和启动校准有效性；高优先级读取端遇到发布中快照会立即返回失败，不会读取 `g_h723_debug.jy901s` 或等待。

## 安装姿态与启动校准

工程车体坐标约定为右手系：`X=车头方向`、`Y=车体左侧`、`Z=向上`。当前
`app_config.h` 配置为 `X<-传感器Y`、`Y<-传感器X` 并反向、`Z<-传感器Z`；如果实际安装方向不同，
只需要修改 `stm32h723_app/App/Inc/app_config.h` 中的
`APP_JY901S_VEHICLE_*_SENSOR_AXIS` 和 `APP_JY901S_VEHICLE_*_SENSOR_SIGN`。
三个轴索引必须互不相同，符号只能是 `1` 或 `-1`。

当前启动校准已开启。JY901S 上电后车辆必须静止，模块会等待连续 `200` 个完整样本，
约需 2~3 秒；每个样本要求加速度模长在 `0.85~1.15 g`，且三轴角速度绝对值不超过
`3 deg/s`。通过后得到三轴陀螺平均零偏，只保存在 RAM，重启后重新采集。运动会清空连续计数，
超过 `5000 ms` 仍未满足条件则校准失败，但原始数据继续保留。

安装造成的 Roll/Pitch/Yaw 固定零点可通过以下配置项手动修正：

```c
#define APP_JY901S_ROLL_OFFSET_DEG 0.0f
#define APP_JY901S_PITCH_OFFSET_DEG 0.0f
#define APP_JY901S_YAW_OFFSET_DEG 0.0f
```

校准后的结果位于 `g_h723_debug.jy901s.vehicle_acceleration_g`、
`vehicle_angular_rate_dps` 和 `vehicle_angle_deg`；`calibration_valid`、
`calibration_status`、`calibration_reason` 和 `gyro_bias_dps` 用于判断结果是否有效。
当前只处理正交轴映射和陀螺零偏，不做小角度倾斜的完整矩阵/四元数标定、六面体加速度标定或磁场标定。

## 校准验证步骤

1. 让车架静止，确认 `sample_valid=1`，等待 `calibration_valid=1`。
2. 静止时观察 `vehicle_angular_rate_dps[0..2]` 应接近 `0 deg/s`。
3. 水平放置车辆，观察 `vehicle_acceleration_g[2]` 接近 `+1 g`。
4. 分别绕车体 X、Y、Z 轴缓慢转动，确认对应角速度和姿态角的正负方向。
5. 只有上述验证完成后，才允许后续控制模块消费车体坐标数据。

## UART8 VOFA

当前 `APP_JY901S_VOFA_TELEMETRY_ENABLE` 为 `0U`；设为 `1U` 可开启遥测。开启后，UART8 每 5 ms 使用 VOFA+ JustFloat 发送十通道：

`Ax, Ay, Az, Gx, Gy, Gz, Roll, Pitch, Yaw, TemperatureC`

单位依次为 `g, g, g, deg/s, deg/s, deg/s, deg, deg, deg, degC`。该宏与 `APP_VOFA_HEALTH_TELEMETRY_ENABLE` 编译期互斥，不能同时开启。

当前 `APP_JY901S_VOFA_CALIBRATED_ENABLE` 为 `1U`；将其设为 `0U` 时，以上十通道保持传感器原始坐标。设为 `1U` 时，三轴加速度、
角速度和姿态角改为车体坐标下的校准结果；温度保持不变。该开关不改变
`g_h723_debug.jy901s` 中的原始字段。

## 水管倾角闭环

JY901S 现在是 ID 3 水管倾角外环的唯一 IMU 输入。`chassisTask` 只在 ID 3 已归零、ID 3 反馈新鲜、JY901S 快照年龄不超过 `30 ms`、`sample_valid=1`、`calibration_valid=1` 且已成功捕获水管水平零偏时处理新完整样本；否则冻结最后安全位置请求并清除 PID 积分。未捕获零偏时会报告 `APP_TILT_FAULT_ZERO_NOT_CAPTURED`，不会因启动姿态偏移主动驱动 ID 3。

控制反馈固定为 `vehicle_pitch_deg = vehicle_angle_deg[1]`，手动调平后通过 `capture_zero_request` 捕获零偏，并计算 `tilt_deg = -(vehicle_pitch_deg - captured_zero_deg)`。因此水管车尾下降时校准 pitch 应增大、`tilt_deg` 变负；`target_tilt_deg=+0.5f` 时应使校准 pitch 减小、ID 3 目标位置减小并抬高车尾。外环随 JY901S 的 200 Hz 完整样本以 `5 ms` PID 步长运行，使用 `motor_target_deg -= pid_rate_deg_s * 0.005f`，仅生成位置请求，不绕过 `app_balance` 的归零、范围、速度、电流和 CAN 保护。

水管外环使用局部两自由度 PID：P/I 使用 `target_tilt_deg - tilt_deg`，D 使用 `-Kd * d(tilt_deg)/dt`，不对目标倾角求导。`g_h723_debug.tilt.derivative_filter_N` 以一阶低通滤波 D 的测得角速度，默认 `20 s^-1`，可在 Keil Watch 实时调整；`0` 为不滤波。首次启用、IMU/反馈恢复和零偏捕获后的第一个完整样本只建立历史，D 输出固定为零。输出速率或位置目标被限幅时拒绝向饱和方向的积分。

本轮不向 JY901S 发送配置命令，也不写入片内 Flash。
